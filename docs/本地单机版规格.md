# 微光写作台本地单机版规格

## 产品边界

- Windows 桌面应用
- 默认浅色界面
- 不提供本地 AI 模型
- 用户自带 OpenAI 兼容 API
- 不提供账号、订阅、云同步、遥测和自有业务服务器
- 应用内不使用 Git 仓库

## 数据真源

- SQLite 保存项目、正文、故事圣经、时间线、伏笔、长期记忆和分析报告
- TipTap/ProseMirror JSON 是正文存储格式
- 场景恢复点保存在本地 SQLite
- 完整项目备份导出 JSON，包含长期记忆、恢复点和分析报告
- API Key 不进入项目数据库和备份

## AI 边界

- 仅用户主动操作时发起网络请求
- 请求直连用户配置的模型 API
- 不内置模型额度
- 不改写未经用户确认的正文
- 改写采用 Diff 审批
- 长期记忆采用候选和作者确认机制

## 发布目标

- 可离线编辑、搜索、查看设定和恢复版本
- 有网络和 API Key 时可使用 AI
- 关闭网络后不影响本地写作数据
- 通过 MIT License 开源
